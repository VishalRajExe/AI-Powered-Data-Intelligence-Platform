3. Agentic Browser — useful, but DON'T make it the core

Repository:

Agentic Browser GitHub

This project has a nice architecture:

              USER PROMPT
                   ↓
             Planner Agent
                   ↓
            Browser Agent
                   ↓
            Critique Agent
                   ↓
          Continue / Correct

The planner creates steps, the browser executes them, and the critique agent evaluates whether each step succeeded. It uses Playwright/browser interaction and supports natural-language research and extraction.

That's an excellent architectural idea for your workflow engine.

But there is a significant licensing consideration: its current license is the TheAgentic Community License Agreement, which restricts use for an online service that competes with TheAgentic products/services.

So for your hackathon, I'd study its architecture rather than directly merging its code unless your team has reviewed and accepts that license.
